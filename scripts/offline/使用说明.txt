NMRPeakQuery 离线版（便携文件夹版）
====================================

本目录是 NMRPeakQuery 的完整本地版本，数据集已随包携带，无需联网即可使用。

一、启动方式
------------
Windows：
    双击本目录下的「启动.bat」，服务自动启动并打开浏览器。
macOS / Linux：
    在本目录执行：  node serve.mjs
    （首次使用可先执行 chmod +x start.sh，然后 ./start.sh）

启动后浏览器会打开 http://127.0.0.1:5177/ ，关闭命令行窗口即停止服务。

二、运行环境
------------
需要目标机器安装 Node.js 18 或更高版本（仅用于提供本地静态服务）：
    https://nodejs.org
若目标机器无法安装 Node.js，请改用「单文件版」：
    NMRPeakQuery-offline.html —— 双击即可用，无需任何依赖。

三、可选参数
------------
    node serve.mjs --port 8080     指定端口（被占用时自动顺延）
    node serve.mjs --no-open       启动后不自动打开浏览器

四、关于离线与 AI 助手
----------------------
- 位移检索、多峰协同、名称/CAS 检索、溶剂峰提示等功能全部在浏览器本地完成，
  数据已内置，完全离线可用。
- AI 助手（数据集核验 / 实验方法解析 / 谱图归属）需要访问你配置的模型服务端点，
  因此在无网环境下不可用；应用会自动探测并降级，不影响其余功能。
  联网时可在右上角「AI 设置」中填入 Base URL / API Key / 模型后使用。

五、数据来源
------------
数据整理自 Gottlieb (1997) / Fulmer (2010) / Babij (2016) / Cseri (2023) 四篇文献，
另有 Sigma-Aldrich 厂商参考表作补充。结果仅供结构解析辅助参考，不作为定量依据，
使用前请与原文核对。
